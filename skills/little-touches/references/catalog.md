# Catalog of little touches

These are details Benji Taylor has posted about from Honk, Family, Lens, Aave, and 𝕏. Each one has a link to its source. Use them as patterns to adapt. Don't copy them as features. Most posts include a short video, and watching it at 0.5× shows more than a description can.

He rarely gives numbers. No post or essay found so far gives a duration, easing curve, or spring value. Any values in [recipes.md](recipes.md) are starting points from this skill, not his.

## Travel and continuity

| --- | --- | --- |
| After a send or swap, the submit spinner moves into the activity tab icon, where the transaction then shows as pending | Shows where the pending item went and where to look next | [post](https://x.com/benjitaylor/status/1744041802444005848) |
| The typed amount moves onto the confirm screen | People can see that the amount didn't change. He calls it "a nice example of a functional animation" | [post](https://x.com/benjitaylor/status/1611422799515746304) |
| Only the changed word animates when the rest of a sentence stays ("Learn more about …") | Avoids "redundant duplication/motion" | [post](https://x.com/benjitaylor/status/1744389230007382086) |
| Each comma moves as the number grows or shrinks | Keeps a daily input lively without slowing it | [post](https://x.com/benjitaylor/status/1743646973771571435) |
| The close X and the back chevron are one icon that morphs | A sheet changes from dismiss to step back without a jump | [post](https://x.com/benjitaylor/status/1705000013829644384) |
| Button labels morph through shared letters ("Con" in Continue → Confirm) | A meaningful change gets noticed | [essay](https://benji.org/family-values#fluidity-through-seamless-transitions) |
| Tabs slide in the direction of the tab that was tapped | "We fly instead of teleport" | [essay](https://benji.org/family-values#fluidity-through-seamless-transitions) |
| A speed-up spinner moves into the original pending tray | Shows which transaction the action affects | [essay](https://benji.org/family-values) |
| Addresses animate into their groups when sorted | Without it, "the static approach feels like digital whiplash" | [essay](https://benji.org/family-values) |
