Little touches

Five small details that help people follow what changed. Things travel instead of being replaced, and only the part that differs moves.

Reduced motion is honored: everything reaches the same end state without travelling.

01

Send flow

The amount you type is the same element you confirm, and the spinner leaves the button for the tab where the result will appear. You always know what was sent and where to look next.

  • Commas slide. Type four digits and the separator moves into place.
  • “Con” holds still while Continue becomes Confirm.
  • The amount travels to the review screen. It is moved, never copied.
  • The spinner lands on Activity and waits there as a pending ring.
  • Go over $2,400 to see the over-balance state.

02

Stepped sheet

Each step has its own height, and one icon closes the sheet or steps back. The height change shows that the step changed, and the icon shows how to undo it.

03

Icon morphs

Every icon is the same three lines redrawn, so one shape changes instead of two crossfading. Click quickly: each morph starts from wherever the lines are.

menu

04

Directional tabs

Content moves toward the tab you picked and the marker slides with it, so you can see which way you went.

05

Empty state

When a filter finds nothing, the sentence stays and only the noun changes. It still reads as the same list, and there is a way back.
